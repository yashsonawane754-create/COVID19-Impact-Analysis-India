# COVID19-Impact-Analysis-India
This project provides a comprehensive data-driven analysis of the COVID-19 pandemic's impact in India. 
It uniquely bridges the gap between Public Health Metrics (vaccination and recovery) and Economic Impact (business sector net worth and digital transformation).


### Aim: 
Analyse how the pandemic changed global economic patterns and market volatility to help businesses manage financial risk.

### Action: 
Consolidated large global datasets into MS Excel, cleaned data, and built dynamic dashboards using Advanced Pivot Tables, VLOOKUP/XLOOKUP, and conditional formatting.

### Outcome: 
Created a centralized interactive Dashboard that simplified complex trend analysis, allowing stakeholders to identify market recovery timelines easily.
